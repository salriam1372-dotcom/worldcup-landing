اتصال به دیتابیس

داخل فایل، مقدار API_ENDPOINT را با آدرس Google Apps Script، Supabase Function یا API خودت پر کن. بعد از هر ثبت‌نام/پیش‌بینی، اطلاعات با POST ارسال می‌شود.
